# Projet 09 - Pipeline d'orchestration des flux BottleNeck (Kestra)

> Formation Data Engineer - OpenClassrooms | Outils : Kestra, DuckDB, Python

## Objectif

Mettre en place un pipeline d'orchestration des flux de donnees pour BottleNeck, un marchand de vins en ligne. Le pipeline analyse 712 produits, calcule un chiffre d'affaires de 65 402 euros et identifie 30 vins premium par score z.

## Competences travaillees

- Conception et implementation d'un workflow d'orchestration avec Kestra
- Analyse de donnees avec DuckDB
- Identification de produits premium par methode statistique (score z)
- Documentation technique (journal de bord, rapport)

## Contenu du repo

- Selmen_Oumayma_2_Workflow_042026.yaml : workflow Kestra complet
- Selmen_Oumayma_1_Diagramme_042026.drawio : diagramme du pipeline
- Selmen_Oumayma_3_rapport_042026.xlsx : rapport d'analyse
- Selmen_Oumayma_4_Extractions_vins_premium_export_042026.csv : 30 vins premium identifies
- Selmen_Oumayma_5_Extractions_vins_ordinaires_export_042026.csv : catalogue vins ordinaires
- Selmen_Oumayma_6_presentation_042026.pptx : support de presentation
- Selmen_Oumayma_7_Journal_de_bord_042026.pdf : journal de bord complet

## Resultats cles

- 712 produits analyses
- Chiffre d'affaires total : 65 402 euros
- 30 vins premium identifies par score z
